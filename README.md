# e-plantShopping

## Project Name

e-plantShopping - Online Houseplant Shopping Application

## Project Description

e-plantShopping is a React-based online houseplant shopping application developed as part of the Coursera Final Project.

The application allows users to browse different categories of houseplants, view plant details and prices, add plants to the shopping cart, manage item quantities, and view the total cart amount.

## Technologies Used

* React
* JavaScript
* HTML
* CSS
* Redux
* Vite

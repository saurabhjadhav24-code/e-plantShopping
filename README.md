\# Paradise Nursery



\## Project Name



Paradise Nursery - Online Houseplant Shopping Application



\## Project Description



Paradise Nursery is a React-based online houseplant shopping application.



The application allows users to browse different categories of houseplants,

add plants to a shopping cart, update quantities, remove products, and view

the total cart amount.



\## Technologies Used



\- React

\- Vite

\- JavaScript

\- React Router

\- Redux Toolkit

\- React Redux

\- CSS

\- GitHub



\## Features



\- Paradise Nursery landing page

\- Get Started button

\- Houseplant product listing

\- Three plant categories

\- 18 unique houseplants

\- Product thumbnails

\- Product names and prices

\- Add to Cart functionality

\- Dynamic cart count

\- Increase quantity

\- Decrease quantity

\- Delete products

\- Cart total calculation

\- Checkout Coming Soon message

\- Continue Shopping functionality

\- About Us page
